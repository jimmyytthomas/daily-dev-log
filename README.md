# Daily Dev Log

A daily record of what I am learning, building, and working on across computer science, software development, home lab projects, cybersecurity, and related technical work.

## Structure

Daily entries are stored directly in the `logs/` folder:

```text
logs/
├── YYYY-MM-DD.md
├── YYYY-MM-DD.md
└── ...
```

These entries are meant to be concise, honest records of real work and learning.
