## What I Learned

- The practice project is useful because it gives the agent known bugs to diagnose and lets me measure how well it performs.
- Claude chooses which tool to request, but my Python code actually runs the tools and controls the safety limits.
- Code-level guardrails are stronger than just telling the model what not to do.
- Test coverage matters because a passing test suite can still miss bugs.
