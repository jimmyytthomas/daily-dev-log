# October 29, 2026

## Projects / Coding

- Continued learning about AI agent frameworks after finishing the `debug-agent` project.
- Learned that agent frameworks provide ready-made pieces that make development faster, but can reduce control and make debugging harder.
- Learned the basic difference between LangChain and LangGraph.
- LangChain connects steps in a mostly linear chain, such as prompt → model → output.
- LangGraph represents agent workflows as a graph with nodes, edges, conditional branches, loops, and shared state.
- Learned how state can track things like a step counter and help enforce limits on an agent.
- Started learning about multi-agent systems where different agents handle different roles.

## What I Learned

- Building an agent yourself gives more control, while frameworks can make larger systems faster to build.
- LangChain is useful for connecting reusable AI components and swapping models.
- LangGraph is better suited for workflows that need decisions, loops, and shared state.
- Multi-agent systems can divide work across specialized agents, but they also add more coordination and complexity.
