# October 30, 2026

## What I Learned

- Multi-agent systems can improve specialization, but they also add cost and complexity.
- AutoGen is useful for collaborative back-and-forth work, while CrewAI fits more structured multi-step jobs.
- Separate agents can be useful when independent checking or very different skills are needed.
- Emulation itself can be legitimate, but bypassing modern security protections creates a separate legal issue.

## Computer Science / School

- Worked on a cybersecurity case study paper about Nintendo's lawsuit against the Yuzu Switch emulator.
- Looked at DMCA Section 1201, security circumvention, emulation, and the difference between creating an emulator versus distributing copyrighted games.
- Focused on the idea that emulation itself can be legitimate, but bypassing modern security protections and profiting from that circumvention creates a different legal issue.

## Projects / Coding

- Continued learning about multi-agent AI systems.
- Learned that using multiple agents can increase cost, latency, debugging difficulty, and the risk of agents passing incorrect information to each other.
- Learned how AutoGen lets agents collaborate through back-and-forth conversations, with limits such as max turns or stop phrases to prevent endless loops.
- Learned how CrewAI organizes agents into roles, goals, and ordered tasks for workflows with clear stages.
- Learned that it usually makes sense to start with one agent and only split into multiple agents when the task becomes too complex.
- Used a test-writer agent and debugger agent as an example of when specialization could help prevent one agent from grading its own work.
