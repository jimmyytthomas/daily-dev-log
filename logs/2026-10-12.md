## What I Learned

- Semantic search can find relevant information even when the user’s wording does not match the source text.
- Retrieval quality depends heavily on chunk quality.
- Clean section boundaries can improve search results more than just changing the search code.
- Conflicting source data is a content problem, not something the model should silently guess through.
- API and setup tokens should be treated like passwords and kept out of source control.
