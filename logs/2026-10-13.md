## Evaluation

- Built `evaluate.py` with 5 test questions.
- Added an answer key for each test that checks:
  - Words the response must contain.
  - Words the response must not contain.
  - Which chunk the retriever should find.
- Used the tests to evaluate retrieval and generation separately.
- First run scored 4/5, but found that the failed test was wrong rather than the bot.
- Fixed the test and got 5/5 on the second run.

## What I Learned

- Error messages can help isolate which stage of a pipeline actually failed.
- Retrieval and generation should be tested separately.
- When a test fails, the test itself can be wrong too.
- Testing for the behavior you want is stronger than trying to ban every possible wrong answer.
- Regression testing is useful after prompt changes so one fix does not quietly break something else.
